# Modeling Child Reaction Dynamics in Child-Robot Interaction using Neural ODEs

**Course:** EN.560.652.01.FA25 — Scientific Machine Learning for Dynamics and Control  

---

## Overview

This project frames child–robot interaction as a controlled continuous-time dynamical system and applies Neural Ordinary Differential Equations (Neural ODEs) to detect children's behavioral reactions to robot errors. We compare three models under leave-one-subject-out (LOSO) cross-validation:

- **Logistic Regression (LR)** — non-temporal feature baseline
- **LSTM** — discrete-time temporal baseline  
- **Neural ODE** — continuous-time SciML model (primary contribution)

**Key result:** Neural ODE achieves the best macro F1 (0.558) and balanced accuracy (0.585), outperforming both LSTM and LR under proper nested validation with early stopping on validation F1.

## Data

The dataset consists of 308 annotated error events from 10 children interacting with the ELLA robot across 103 sessions. Due to privacy constraints, raw video data is not publicly available.

**Expected directory structure on your machine:**
```
/path/to/Sciml/
├── ELLA_Error_Lables.csv    # Annotation file (308 events, 10 children)
├── videos/                  # Raw .mp4 session videos (76 files)
├── features_cv/             # Extracted optical flow features (auto-generated)
└── manifest_cv.csv          # Feature index (auto-generated by extract_cv.py)
```

Update the `BASE_DIR` path at the top of each script to match your local setup.

## Usage

### Quick start (single executable)

```bash
# First update BASE_DIR in each script to match your data path
python run_all.py
```

This runs all three steps in order and outputs `results_summary.txt` and `fig_*.png`.

---

### Step-by-step

```bash
python extract_cv.py
```

- Reads `ELLA_Error_Lables.csv` and all `.mp4` files in `videos/`
- Computes dense optical flow (Farneback) for each annotated event
- Outputs `features_cv/event_XXXX.npy` — shape `(18, 3)` per event
- Outputs `manifest_cv.csv` — index mapping event IDs to feature paths

### Step 2: Train and evaluate models

```bash
python train_val.py
```

- Reads `manifest_cv.csv` and `features_cv/`
- Runs LOSO cross-validation (8 train / 1 val / 1 test per fold)
- Early stopping on validation macro F1 (patience=15)
- Outputs `results_loso.csv` and `results_summary.txt`

### Step 3: Generate figures

```bash
python gen_figures.py
```

- Reads `results_loso.csv`
- Outputs `fig_summary.png`, `fig_perfold.png`, `fig_trajectory.png`

## Model Architecture

### Neural ODE (primary model)

```
x(t) ∈ R^3       — optical flow features (mean magnitude, vx, vy)
u   ∈ R^11       — control: one-hot error type (10) + normalized onset time (1)

Encoder:  LSTM(x_{t-T:t}) → h(t₀) ∈ R^32
ODE:      dh/dt = f_θ(h(t), u, t)   [2-layer MLP, tanh, dopri5 solver]
Classify: ŷ = σ(W [h(t₀+Δ); u] + b)
```

Gradients computed via the adjoint method (O(1) memory in ODE steps).

### LSTM baseline

```
LSTM(x) → c_T ∈ R^64
ŷ = σ(W₂ ReLU(W₁ [c_T; u] + b₁) + b₂)
```

### Logistic Regression baseline

```
flatten(x) ∈ R^54, concat u → R^65
ŷ = σ(w^T [flatten(x); u] + b)
```

## Results

LOSO cross-validation (mean ± std, 10 folds, 8 train / 1 val / 1 test):

| Model      | F1 (macro)     | AUC            | Balanced Acc.  |
|------------|----------------|----------------|----------------|
| LR         | 0.527 ± 0.188  | 0.613 ± 0.186  | 0.543 ± 0.181  |
| LSTM       | 0.556 ± 0.166  | **0.670 ± 0.122** | 0.567 ± 0.155 |
| Neural ODE | **0.558 ± 0.172** | 0.645 ± 0.199 | **0.585 ± 0.152** |
